# Szkolenie AI

Repozytorium materiałów szkoleniowych:

| Katalog | Opis |
|---------|------|
| `Demo - 1` | Materiał startowy (strona statyczna) |
| `Demo - 2` | Wtyczka WordPress `us-ogloszenia` |
| `Demo - 3` | Aplikacja **Rezerwacja sal** (Node.js, Express, SQLite) |

Uruchomienie aplikacji z kroku 3: wejdź do `Demo - 3` i wykonaj `npm install`, potem `.\dev.ps1` lub `npm start` (szczegóły w `Demo - 3/README.md`).
